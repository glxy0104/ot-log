# 근무시간 기록 (간호사 초과근무 증거 앱)

현직 간호사가 재직 중에 초과근무 증거를 거의 손대지 않고 쌓아 두었다가, 퇴사 후 최근 3년치 미지급 연장근로수당을 청구할 때 노무사·노동청에 바로 낼 수 있게 정리해 주는 웹앱(PWA)입니다.

- 설치: 주소를 Safari/Chrome으로 열고 "홈 화면에 추가".
- 데이터는 **폰 안에만** 있습니다. 서버·계정·추적 없음. 백업은 JSON 파일로 직접.
- 환자 정보(이름·등록번호·EMR 화면)는 입력·첨부하지 않도록 안내합니다.

## 어떻게 쓰나
1. 처음 한 번: 안내 5장(왜 청구할 수 있는지, 법·판례) → 근무조 시각·급여일 설정 → 폰 자동화 설치 안내.
2. 매달 한 번: 근무표 입력(달력 탭, 글자 붙여넣기, 또는 캡처 인식 — OCR은 브라우저 안에서만 실행).
3. 매주 한 번: iPhone 단축어 자동화가 남긴 `근무기록.txt`(도착·출발 시각)를 홈 › 가져오기.
4. 필요할 때: 지시 근거 캡처·메모, 시간외 신청 여부, 휴게 미사용, 동료, 병원 기록 체크.
5. 퇴사 때: 월별 CSV·PDF·JSON 내보내기, 시효·내용증명 마감 안내.

자동화는 iOS 기본 '단축어' 앱의 도착/출발/시간/Wi-Fi/NFC 트리거를 씁니다(앱 안 "자동화 설치 안내"). 파일 한 줄 형식은 `2026-10-27 06:31 in` / `... out` 이며, 같은 형식이면 Android 자동화 앱(MacroDroid·Tasker 등)으로 만든 파일도 가져올 수 있습니다.

## 설계 원칙
- 당일 기록과 사후 복원을 구분하고, 수정하면 원래 값·수정 시각이 남습니다(덮어쓰기 없음).
- 분 단위 기록. 법정 수당 추정 = 초과 × 통상시급 × 1.5 + 야간(22~06) 겹침 × 0.5. 금액은 추정치이며 최종 계산은 노무사가 합니다.
- 시효는 월급날마다 따로 3년. 퇴사 후에는 내용증명 → 6개월 내 소송·지급명령 마감을 보여 줍니다.

## 개발
- 파일 하나(`index.html`) + `manifest.json` + `sw.js` + 아이콘. 의존성 없음(캡처 인식 때만 Tesseract.js를 CDN에서 내려받음).
- 점검: `node test.js`
- 배포: 정적 호스팅 아무 곳이나(GitHub Pages 등). 새 버전을 올릴 때 `sw.js`의 캐시 이름(`otlog-vN`)을 올리세요.

## 면책
이 앱은 법률 자문이 아닙니다. 법·판례 안내는 공개 자료를 바탕으로 했으며, 실제 청구 전에 노무사 상담으로 확인하세요.
